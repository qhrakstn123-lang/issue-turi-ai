# 편집 지시 기준

## 장면 길이

MVP 기본값은 장면당 2~5초다. 자동 영상 생성 단계에서는 TTS 오디오 길이에 맞춰 `actual_duration`을 채운다.

## 모션

- `zoom_in`: 후킹과 중요한 이미지 강조
- `pan_left`, `pan_right`: 정지 이미지에 흐름 부여
- `shake`: 논란, 충격, 반응 강조
- `text_pop`: 강조 자막 등장
- `fade_in`, `fade_out`: 정리 또는 마무리

## 효과음

- `whoosh`: 화면 전환
- `pop`: 자막 등장
- `impact`: 충격적인 내용
- `click`: 정보 전환
- `alarm`: 논란/위험 느낌
- `suspense_rise`: 반전 전 긴장감
- `hit`: 결론 강조
