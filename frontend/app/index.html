Legacy / Deprecated

ShortsFlow Next.js frontend를 사용하세요

이 주소는 backend API 서버와 legacy 정적 안내 화면입니다. 실제 ShortsFlow 작업 화면은 Next.js 앱에서 확인합니다.

Backend API http://127.0.0.1:8000
Main UI http://localhost:3000
Legacy UI frontend/app

실행 방법

  1. backend uv run --project . python -m backend.src.presentation.http.server
  2. frontend cd frontend/web && npm run dev
  3. browser http://localhost:3000 또는 Next.js dev server가 안내하는 실제 포트

앞으로 UI 작업은 frontend/web에서만 진행합니다. frontend/app은 삭제하지 않고 legacy static frontend로 보존하며 신규 기능을 추가하지 않습니다.
